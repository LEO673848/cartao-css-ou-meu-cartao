# Projeto Cartão CSS
 
## Descrição
 
Este projeto foi desenvolvido para praticar conceitos básicos de CSS, explorando como propriedades de estilo influenciam a aparência dos elementos em uma página web.
 
Durante a atividade, foram realizados testes com as propriedades `width`, `height` e `padding` para compreender melhor como elas afetam o tamanho e o espaçamento interno de um cartão. As modificações permitiram observar visualmente as diferenças na organização e apresentação do conteúdo.
 
## Alterações Realizadas
 
- Alteração da largura (`width`) do cartão.
- Alteração da altura (`height`) do cartão.
- Ajuste do espaçamento interno (`padding`).
- Atualização da página para verificar os resultados de cada modificação.
 
## Aprendizados
 
Com esta atividade, foi possível compreender a importância das propriedades de dimensão e espaçamento no CSS, além de perceber como pequenos ajustes podem melhorar a organização, a legibilidade e o visual de uma interface.
 
## Tecnologias Utilizadas
 
- HTML5
- CSS3
 
## Objetivo
 
Desenvolver familiaridade com as principais propriedades de estilização do CSS e entender como elas contribuem para a construção de layouts mais organizados e atraentes.
